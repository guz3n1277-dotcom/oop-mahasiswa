# PHP OOP CRUD Mahasiswa

Aplikasi pengelolaan data mahasiswa sederhana menggunakan PHP OOP dan MySQL.

## Fitur

* Menampilkan data mahasiswa
* Menambahkan data mahasiswa
* Mengubah data mahasiswa
* Menghapus data mahasiswa
* Validasi NIM agar tidak duplikat

## Teknologi

* PHP
* MySQL
* MySQLi
* Git dan GitHub

## Cara Menjalankan

1. Jalankan Apache dan MySQL melalui XAMPP.
2. Pastikan database `akademik` dan tabel `mahasiswa` sudah tersedia.
3. Simpan proyek di folder `htdocs`.
4. Buka `http://localhost/LatihanPHP/oop-mahasiswa/` melalui browser.
